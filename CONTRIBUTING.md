# Contributing

Contributions are welcome!

- **Bug reports**: open an issue in the extension's repository, using the bug report form.
- **Everything else** (questions, feature requests, ideas, general discussion): [use Discussions](https://github.com/orgs/phpbbmodders/discussions), or the [community forum](https://www.phpbbmodders.com/community/).
- Pull requests are welcome for bug fixes or discussed features.

## Pull requests

- Target the repository's default branch.
- Follow the [phpBB coding guidelines](https://area51.phpbb.com/docs/dev/3.3.x/development/coding_guidelines.html). Each repository's CI runs phpBB's code sniffer and extension validator (EPV) plus a PHP syntax check; please make sure they pass.
- Keep a pull request to one fix or feature.
- Supported versions: phpBB 3.3.19 or later, and the PHP versions listed in the extension's `composer.json` (PHP 7.4 or later).
