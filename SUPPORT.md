# Getting help

- **Questions, ideas, and feature requests:** [phpBB Modders Discussions](https://github.com/orgs/phpbbmodders/discussions)
- **General phpBB and extension support:** [phpBB Modders community forum](https://www.phpbbmodders.com/community/)
- **Bug reports:** open an issue in the extension's own repository, using the bug report form.
- **Security problems:** see [SECURITY.md](SECURITY.md). Do not post them publicly.
